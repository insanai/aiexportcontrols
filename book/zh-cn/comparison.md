# 08. 两种制度怎样相遇

## 比较具体关口

中国第48号公告关注境内技术向境外转移，并明确所有权和控制变化。美国框架关注受管辖物项、目的地、用户和用途，并在特定条件下触及外国制造物项。同一AI项目可能在不同阶段面对两种制度。[CN48](https://www.mofcom.gov.cn/zwgk/zcfb/art/2026/art_0a31a3c9ac404f7a9b0e917ce3412997.html) [EAR734](https://www.bis.gov/regulations/ear/734) [EAR742](https://www.bis.gov/regulations/ear/742) [EAR744](https://www.bis.gov/regulations/ear/744)


| 问题 | 中国 / 第48号公告 | 美国 / EAR |
| --- | --- | --- |
| 主要关口 | 技术转移及所有权和控制变化 | 物项、目的地、用户和用途 |
| 公开AI | 草案排除已有公开技术 | 公开信息规定和4E091注释 |
| 新开源 | 限制类技术拟适用便利措施 | 核对公开条款及模型规则状态 |
| 硬件 | 芯片设计知识及指定光伏设备 | 先进芯片及指定制造物项 |
| 状态 | 登记已开始，目录新增仍为提案 | 芯片规则及模型不执行争议 |

设想中国开发者在海外计算中心使用受美国规则覆盖的芯片，然后将私有模型技术许可给海外伙伴。芯片、使用者和用途可能涉及美国规则，模型转移可能涉及中国登记及技术类别。一个制度下的合法路径不能证明另一个制度也已满足。这是假设案例，不是对真实公司的指控。[CN48](https://www.mofcom.gov.cn/zwgk/zcfb/art/2026/art_0a31a3c9ac404f7a9b0e917ce3412997.html) [CN-A1](https://www.mofcom.gov.cn/api-gateway/jpaas-web-server/front/document/download?fileUrl=YW5UzzlvCwcM%2FNHHX%2FtT6KYc7i4iYCs13RxyX1cYsF7Mi050tv2zWwJDAqyqUOFf3lPQeAoPgP%2BrmQMGF7Tta7RdRW1C2hni5Ufl7eigFU2aoR9BIV7bpVR%2BwDBnd46wm5m7QVY2Mj%2FXPJaIbSdBzxKM6WqPb1yMuUzPhfLWixM%3D&fileName=1.%E6%8B%9F%E5%88%97%E5%85%A5%E3%80%8A%E4%B8%AD%E5%9B%BD%E7%A6%81%E6%AD%A2%E5%87%BA%E5%8F%A3%E9%99%90%E5%88%B6%E5%87%BA%E5%8F%A3%E6%8A%80%E6%9C%AF%E7%9B%AE%E5%BD%95%E3%80%8B%E7%9A%84%E4%BA%BA%E5%B7%A5%E6%99%BA%E8%83%BD%E3%80%81%E7%94%9F%E7%89%A9%E5%8C%BB%E8%8D%AF%E3%80%81%E5%85%89%E4%BC%8F%E6%8A%80%E6%9C%AF%E8%8C%83%E5%9B%B4%EF%BC%88%E5%BE%81%E6%B1%82%E6%84%8F%E8%A7%81%E7%A8%BF%EF%BC%89.wps) [EAR744](https://www.bis.gov/regulations/ear/744)

更多文书、托管服务或不同建厂地点都是可能机制，并非已证实结果。公告本身无法量化价格、就业、投资、能源或AI性能影响。本书不作数值预测。
